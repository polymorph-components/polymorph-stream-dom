polymorph:stream-dom demos

Dioxus TodoMVC — a Rust/Dioxus app compiled to a polymorph:stream-dom producer component.

Dominator TodoMVC — the same TodoMVC app, this time built with Rust/Dominator.

Both stream their DOM mutations across the same wire into this page's receiver. Demos default to the native DOM receiver; add ?receiver=remote to the URL to switch to the remote-dom DOMRemoteReceiver instead.

Benchmark page — a js-framework-benchmark-shaped row table, run under tachometer.
